# Submission checklist

Same repository for both units:
https://github.com/winaung786/ai201-project1-unofficial-guide-starter-v2026

This checklist points to canonical evidence. It does not maintain a second
set of verdicts, token totals, or provenance notes.

| Requirement | Canonical evidence |
|---|---|
| Preserve Unit 1 criteria and legitimate revisions | [criteria.md](criteria.md), with dated originals/revisions; [criteria history](CRITERIA_HISTORY.md) records historical provenance |
| Same application, corpus, questions, and model | [Unit 2 scope](README.md#unit-2--testing-the-same-rag-system-september-22-2026) and each raw JSON's configuration |
| Before: five criteria, three runs, real output | [Run Log — Before](README.md#run-log--before) and its linked JSON/Markdown |
| Explain every verdict and diagnosis | [Verdicts](README.md#verdicts), [Diagnoses](README.md#diagnoses), and separate supplemental failure diagnoses |
| One required primary improvement | [The Improvement](README.md#the-improvement--selected-before-implementation), followed by the original after evaluation |
| Repeat full evaluation after the primary change | [Run Log — After](README.md#run-log--after) |
| Honest comparison and remaining limitations | [Before vs. After](README.md#before-vs-after), [What's Still Broken](README.md#whats-still-broken) |
| Review criterion quality and disclose AI help | [What I'd Do Differently](README.md#what-id-do-differently), [How ChatGPT Helped](README.md#how-chatgpt-helped-in-unit-2) |
| Separate retrospective scores from live trials | [Scorer verification](results/scorer_verification.md), plus clearly labeled raw live logs |
| Generate counts/token totals without narrative drift | [evaluation_summary.md](results/evaluation_summary.md), generated by `tools/summarize_evaluations.py`; `--check` detects a stale report |
| Optional second improvement and full post-stretch evidence | [October 1 feedback follow-up](README.md#october-1-feedback-follow-up) |
| Recover interrupted runs; supported pacing | [RUNNING.md](RUNNING.md#about-rate-limits), `run_eval.py`, and synthetic failure-injection tests in `tests/test_eval_recovery.py` |
| Runtime verification and current automated tests | Actual execution evidence linked in the October 1 follow-up |
| Preserve Git history | Existing repository history; no historical raw result files rewritten |

The latest instructor rubric gives no original-miss diagnosis points when the
original miss list is empty. Supplemental failures are kept distinct; no
passing original criterion is relabeled to change that score. The instructor
decides the grade after reviewing any new evidence.

The student handles Course Portal submission. Setup/reproduction instructions
are in [RUNNING.md](RUNNING.md); a Gemini key stays in the ignored local `.env`.
Historical Unit 1 order/authorship limitations remain in
[ASSIGNMENT_REVIEW.md](ASSIGNMENT_REVIEW.md) and [WORK_LOG.md](WORK_LOG.md).
